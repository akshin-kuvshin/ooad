(2) Диаграммы деятельности:

Сценарий 1: :Point.RequestAccess(key:Key).
Участники: point:Point (p), :Controller (c), key:Key (k), :Journal (j), :DateTime (dt).
Сверху вниз:
1) {p->c} accessAllowed = CheckKey(key, this);
2) {c->dt} time = Now;
3) {c->k} rules = GetRules();
4) {c->c} status = checkRules(rules, time);
5) {c->j} addEvent(key, point, time, status);
# alt [accessAllowed == true] 6) {p->p} open();
# else 7) {p->p} reject();
# alt end.

Сценарий 2: :Controller.checkRules(rules:Rule[*], time:DateTime).
Участники: :Controller (c), time:DateTime (dt), :TimeOnly (to), rule:Rule (r), ruleArea:Area (ra).
Сверху вниз:
1) {c->dt} dayOfWeek = DayOfWeek; // 0 = Sunday
2) {c->c} dayOfWeek = (dayOfWeek + 6) % 7; // 0 = Monday
3) {c->to} timeOnly = FromDateTime(time);
# loop [for each rule in rules]:
4) {c->r} accessAllowed = Allows(controllerArea, dayOfWeek, timeOnly);
5) {r->ra} areaMatches = Equals(controllerArea);
6) {r->r} timeMatches = (accessTimeStart[dayOfWeek] <= timeOnly <= accessTimeEnd[dayOfWeek]);
7) {r->r} allow = areaMatches and/&& timeMatches;
8) {r->c} _return_ allow;
# opt [accessAllowed == true] 9) {c} _return_ true;
# opt end;
# loop end;
10) {c} _return_ false.

Сценарий 3: :Journal.AddEvent(key:Key, point:Point, time:DateTime, result:Boolean).
Участники: :Journal (j), event:Event (e).
Сверху вниз:
1) {j->e} event = new Event(key, point, time, result);
2) {j->j} events.Add(event).

(P.)x6_S.: с символа # начинаются или заканчиваются управляющие фреймы, т.е. условия и циклы; _return_ обозначает сам знаешь что; если не указано, куда возвращать результат - возвращай в левый край диаграммы, т.е. это уже результат всего сценария (всей диаграммы).
(P.)x7_S.: не каждый вызов метода создаёт новую активность на диаграмме; ориентируйся по тому, что написано {в фигурных скобочках}.
