(2) Диаграммы деятельности:

Сценарий 1: sd Point.RequestAccess(key:Key).
Участники: point:Point (p), :Controller (c), Owner:Staff (o), key:Key (k), controllerArea:Area (ca), :Journal (j), :DateTime (dt).
Сверху вниз:
1) {p->c} accessAllowed = CheckKey(key, this);
2) {c->dt} time = Now;
3) {c->p} entry = Entry;
4) {c->o} staffLocation = GetLocation();
# alt [entry == true] 5) {c->c} locationCoincidence = (staffLocation is null);
# else 6) {c->ca} locationCoincidence = Equals(staffLocation);
# alt end;
7) {c->c} accessAllowed = false;
# opt [locationCoincidence == true]:
8) {c->k} rules = GetRules();
9) {c->c} accessAllowed = checkRules(rules, time); // ref на сценарий 2
# opt end;
10) {c->j} EmplaceEvent(key, point, time, accessAllowed, controllerArea); // ref на сценарий 3
# alt [accessAllowed == true] 11) {p->p} open();
# else 12) {p->p} reject();
# alt end;
13) {p} _return_.

Сценарий 2: sd Controller.checkRules(rules:Rule[*], time:DateTime):Boolean.
Участники: :Controller (c), time:DateTime (dt), :TimeOnly (to), rule:Rule (r), ruleArea:Area (ra).
Сверху вниз:
1) {c->dt} dayOfWeek = DayOfWeek; // 0 = Sunday
2) {c->c} dayOfWeek = (dayOfWeek + 6) % 7; // 0 = Monday
3) {c->to} timeOnly = FromDateTime(time); // это статический метод, поэтому lifetime у :TimeOnly - вся диаграмма
# loop [for each rule in rules]:
4) {c->r} accessAllowed = Allows(controllerArea, dayOfWeek, timeOnly);
5) {r->ra} areaMatches = Equals(controllerArea);
6) {r->r} timeMatches = (accessTimeStart[dayOfWeek] <= timeOnly <= accessTimeEnd[dayOfWeek]);
7) {r->r} accessAllowed = areaMatches and/&& timeMatches;
# opt [accessAllowed == true] 8) {c} _return_ true;
# opt end;
# loop end;
9) {c} _return_ false.

Сценарий 3: sd Journal.EmplaceEvent(key:Key, point:Point, time:DateTime, result:Boolean, controllerArea:Area).
Участники: :Journal (j), event:Event (e), Owner:Staff (o).
Сверху вниз:
1) {j->e} event = new(key, point, time, result, controllerArea); // далее в п. 2-8 описывается работа конструктура
2) {e->e} Key_ = key;
3) {e->e} Point_ = point;
4) {e->e} Time = time;
5) {e->e} Result = result;
# opt [Result == true] 6) {e->o} SwitchLocation(controllerArea);
# alt [location is null] 7) {o->o} location = controllerArea; // alt вложен в opt!
# else 8) {o->o} location = null;
# alt end;
# opt end;
9) {j->j} events.Add(event);
10) {j} _return_.
